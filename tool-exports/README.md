# tool-exports

Automated exports of the **live annotation tool's** dataset. This folder is
written by the `Sync annotations from the tool` GitHub Action
([`.github/workflows/sync-annotations.yml`](../.github/workflows/sync-annotations.yml)),
which runs daily and can be triggered manually.

Unlike the `output/` and `hai-annotations/` folders (which hold the AI-pipeline
experiment output and earlier one-off human CSVs), this folder is the current,
auto-refreshed source of truth for what the annotation team has produced.

## Files

- **`annotations.csv`** — the tool's canonical export (its admin "Download all"
  CSV): one row per annotation, merging in-progress and archived filings, and
  including the adjudicated/final columns (`adjudicated_status`, `final_kind`,
  `final_category`, `final_subcategory`, `final_strength`, `final_tags`). To see
  only finalized results, filter to rows where `adjudicated_status` is `agreed`
  or `resolved`. Note: this mirrors the admin export exactly, so it also includes
  the handful of Phase-2 screening/calibration filings.
- **`MANIFEST.md`** — generated each run: timestamp and row count.

Both files are regenerated by the job; don't edit them by hand.

## How it works (read-only, isolated)

The job logs into the live tool as a dedicated read-only service account
(`export-bot`) and downloads `/export.csv`. All the query work happens inside the
app, next to the database, so it finishes in under a minute. The job never
modifies the tool, the tool's database, or anything in this repo outside this
folder — and it only commits when the CSV actually changed.
